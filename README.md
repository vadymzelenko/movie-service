# Кинозал — домашний кинотеатр для Smart TV

Веб-кинотеатр для браузера телевизора (10-foot UI под 55") с пультом на смартфоне:
сканируете QR-код на экране — телефон становится тачпадом, клавиатурой и пультом плеера.

- **`/tv`** — интерфейс телевизора: навигация стрелками пульта, каталог TMDB с рейтингами IMDb/КП, карточка фильма с актёрами и русскими рецензиями, выбор озвучки/качества/сезона/серии, плеер на `hls.js` с таймкодами.
- **`/remote`** — пульт: D-pad, тачпад (жесты или курсор), ввод поиска с дублированием на TV, «Смотреть на ТВ», управление плеером (пауза, ±10 с, таймлайн, громкость).
- **Сервер** — Fastify + Socket.io, SQLite (`node:sqlite`), прокси потоков с вырезанием рекламы из HLS.

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт

Нужен Node.js ≥ 22.13.

```bash
npm install
cp .env.example .env      # ключи необязательны: без TMDB работает демо-каталог
npm run dev               # сервер :4000 + веб :3000
```

1. На телевизоре откройте `http://<IP-компьютера>:3000/tv`.
2. Отсканируйте QR-код в правом нижнем углу телефоном (тот же Wi-Fi).

Если TV открыт как `localhost`, QR всё равно указывает на LAN-IP сервера (`/api/network`).

Продакшен: `npm run build && npm start`.

## Конфигурация (`.env`)

| Переменная | Назначение |
|---|---|
| `TMDB_API_KEY` | v3 API key или v4 Read Access Token — каталог, постеры, описания, актёры на русском |
| `KINOPOISK_API_KEY` | [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech) — рейтинги КП/IMDb и русские рецензии |
| `PROXY_SECRET` | Секрет HMAC для прокси-ссылок (без него — случайный на время процесса) |
| `CORS_ORIGINS` | Разрешённые origin'ы фронтенда; пусто — любой |
| `EXTRACTOR_ALLOWED_HOSTS` | Хосты, во вложенные iframe которых может заходить экстрактор |
| `NEXT_PUBLIC_API_URL` | Адрес сервера для фронтенда; по умолчанию `http://<хост страницы>:4000` |

## Источники видео

Сервер не содержит каталога потоков — их дают провайдеры, выстроенные в **цепочку фоллбеков**:
если у первого нет фильма/серии, он не отвечает (таймаут `PROVIDER_TIMEOUT_MS`) или его поток
упал прямо в плеере, берётся следующий. На TV источники видны как «Источник 1 / 2 / …»
и в карточке тайтла, и в плеере (переключение продолжает с той же секунды).

Порядок цепочки: `library.json` → провайдеры из `providers.json` (в порядке записи) → демо.

| Провайдер | Настройка | Что делает |
|---|---|---|
| `library` | `apps/server/data/library.json` ([пример](apps/server/data/library.example.json)) | Ручное сопоставление: прямые `hls`/`mp4` или `page` — страница плеера, из которой экстрактор достанет манифест |
| `jellyfin` | `providers.json` или `JELLYFIN_URL` + `JELLYFIN_API_KEY` | Ищет тайтл в вашем Jellyfin по TMDB/IMDb ID (или названию и году), серии — по номерам. Аудиодорожки файла → озвучки, профили перекодирования 360p–1080p → качества, H.264/MP4 — ещё и без перекодирования |
| `http` | `providers.json` | Любой ваш REST-бэкенд, который по ID отдаёт JSON с прямыми ссылками: шаблон URL с `{tmdbId}` `{imdbId}` `{season}` `{episode}` `{title}` `{year}`, путь к массиву и имена полей настраиваются |
| `demo` | — | Открытые фильмы Blender Foundation (CC BY) |

Пример конфигурации — [`apps/server/data/providers.example.json`](apps/server/data/providers.example.json).
Свой провайдер в коде — класс с интерфейсом `StreamProvider` (`resolveMedia(params) → потоки | null`)
и одна строка в `providers/registry.ts`.

Все потоки идут через `/proxy/*`: ссылки зашифрованы (ключи API, например Jellyfin, в браузер
не попадают), плейлист очищается от рекламных вставок, сегменты отдаются с поддержкой `Range`.
Используйте только источники, на просмотр которых у вас есть права.

## Управление на TV

| Клавиша | Действие |
|---|---|
| ← ↑ → ↓ | Перемещение фокуса; в плеере со скрытой панелью ← → — перемотка ±10 с (с ускорением при удержании) |
| OK / Enter | Выбрать; в плеере — пауза |
| ↑ / ↓ при скрытой панели плеера | Громкость ±5 % (индикатор в правом верхнем углу) |
| Back / Esc / Backspace | Назад: закрыть меню → плеер → карточку → сбросить поиск → «Главная» |
| Play/Pause, Space | Пауза в плеере |

Таймкоды пишутся в два места: `localStorage` каждые 5 секунд и SQLite-сервер раз в 10 секунд
(и сразу на паузе, перемотке, конце серии, выходе). Если сервер недоступен, позиция помечается
неотправленной и досылается, когда связь вернётся. В конце серии появляется оверлей
«Следующая серия» с отсчётом 8 секунд (Enter — сразу, Back — отмена).

## Структура

```
packages/shared     протокол сокета, типы, zod-схемы
apps/server         Fastify + Socket.io + SQLite + stream proxy
  src/socket          комнаты и ретрансляция событий
  src/metadata        TMDB, Кинопоиск, демо-каталог
  src/streaming       провайдеры, экстрактор, очистка HLS, прокси
  test/               node:test — HLS, экстрактор, подписи, прокси, сокеты
apps/web            Next.js (App Router)
  lib/spatial         движок пространственной навигации
  components/tv       10-foot UI, плеер, карточка тайтла
  components/remote   пульт
```

## Деплой фронтенда на Vercel

В настройках проекта Vercel укажите **Root Directory → `apps/web`** (остальное возьмётся из `apps/web/vercel.json`).
Vercel поднимет только Next.js-часть (`/tv`, `/remote`). Сервер (`apps/server`) там работать не может:
serverless-функции не держат постоянные WebSocket-соединения и не сохраняют SQLite между вызовами.
Запустите сервер дома (мини-ПК, NAS) или на VPS за HTTPS и укажите его адрес в переменной
`NEXT_PUBLIC_API_URL` в Vercel. Адрес обязательно `https://`: страница на HTTPS не сможет обращаться к `http://`-серверу (mixed content).
